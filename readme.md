# OpenCV Image Processing Project

## 项目介绍

本项目基于 Python 和 OpenCV，实现基础图像处理功能，用于学习数字图像处理和计算机视觉相关内容。

## 使用技术

- Python
- OpenCV
- NumPy

## 实现功能

- 图像读取
- 灰度化处理
- 图像滤波
- 边缘检测
- 目标检测

## 项目运行环境

Python 3.14.7

## 项目效果

输入图像：
/opencv_object_detection/test.webp


处理结果：
/opencv_object_detection/result.jpg


## 学习收获

通过本项目熟悉了 OpenCV 基础操作，以及图像处理流程，为后续学习计算机视觉和机器学习相关内容打下基础。
